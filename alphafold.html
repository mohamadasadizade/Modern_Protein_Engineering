3. Mutation modelling

The practical mutation exercise will compare a reference sequence with one or more variant sequences. The predicted structures can be inspected for local and global differences, while recognising that a structural prediction alone does not establish the functional effect of a mutation.

For reproducibility, record the residue numbering convention, chain identifier, reference amino acid, substitution and any changes to the input construct.

4. Analysis and interpretation of results

Interpretation should combine structural inspection with the confidence metrics reported by the selected AlphaFold implementation. Confidence scores are not direct measurements of experimental accuracy, binding affinity or biological activity.

Structural inspection

Check chain identity, residue coverage, missing regions, geometry and relevant interfaces.

Confidence assessment

Inspect the appropriate confidence outputs and identify uncertain regions.

Comparison

Compare reference and variant models using consistent residue mapping and alignment.

Limitations

Document assumptions, model version, input constraints and unresolved uncertainty.
